# Faraway v3 — Plan: Island Escape + AoE Building System

Date: 2026-05-21

## Goal
Transform from passive exploration into an active escape game with AoE-style resource gathering + building placement. Player starts stranded, gathers resources, builds a settlement, assembles a ship, and sails away.

## New files
- `src/building.ts` — building defs, resource node positions, ship recipe data

## Modified files
- `src/types.ts` — ResourceKind, Resources, BuildingKind, PlacedBuilding, ResourceNode, Era, SaveState v3
- `src/game.ts` — build mode, resource gathering, building placement + rendering, era progression, escape sequence

---

## Resources (4 types, top-left HUD)
- Wood (🪵) — from forest-edge nodes, E to gather
- Stone (⛏) — from cave wall nodes, E to gather
- Food (🐟) — from shore/shallows fishing spots, E to gather
- Coin (🪙) — from ruins artifacts, E to salvage

### Resource node positions
| Kind  | Count | Locations |
|-------|-------|-----------|
| Wood  | 8     | Forest edge ring |
| Stone | 5     | Cave entrance cluster |
| Food  | 6     | Shore/shallows |
| Coin  | 4     | Ruins floor tiles |

Each node: fixed position, yields 5–10 per gather, 60s respawn (game time), depleted state tracked in save.flags.

## Buildings (5 types, B key → menu → click tile)
| Kind         | Wood | Stone | Food | Coin | Function |
|--------------|------|-------|------|------|----------|
| Shelter      | 20   | 0     | 0    | 0    | Rest spot, restores essence |
| Workshop     | 30   | 10    | 0    | 0    | Unlocks crafting UI |
| Forge        | 0    | 20    | 0    | 10   | Tool upgrades (faster gather) |
| Signal Fire  | 15   | 0     | 0    | 0    | Reveals ship route, visual effect |
| Dock         | 40   | 20    | 0    | 0    | Ship assembly point |

- Press B to toggle build mode
- Build menu at bottom of screen, shows building options + costs (greyed if unaffordable)
- Mouse hover over world = green ghost preview on valid tiles, red on invalid
- Click to place (deducts resources)
- Only one of each building allowed
- Passability: shelter/workshop/forge/signal_fire are walkable; dock is walkable

|----------|------|-------|------|------|-----------------|
| Hull     | 30   | 10    | 0    | 0    | Dock built |
| Sail     | 10   | 0     | 20   | 0    | Dock built |
| Compass  | 0    | 5     | 0    | 15   | Dock built |

---

## Era progression
1. **Stranded** (start) — gathering speed ×1
2. **Settled** — Shelter + Workshop built → gathering speed ×1.5, banner shown
3. **Ready to Sail** — All 3 ship parts crafted → "Set Sail" at Dock unlocks

---

## Escape sequence
1. All ship parts built → approach Dock + E → "Set Sail" dialog
2. Confirm → player walks south, fade to black (3s)
3. Victory screen: "You escaped Faraway" + play time + discoveries count + era reached
4. Two options: "Sail back" (continue on island) or restart

---

## Build mode UX
- Mouse moves tracked for hover preview
- B key: open/close build mode
- Esc: cancel build mode
- Bottom panel: 5 building icons with costs, click to select
- Cursor crosshair on world canvas in build mode
- Valid placement: passable non-water tile, no existing building at that tile
