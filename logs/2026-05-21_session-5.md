# Session 5 — 2026-05-21

## User message

"yes fix all of it" — blanket approval to fix all broken items from the post-session-4 audit.

## Changes shipped

### 1. Item system now functional (`src/game.ts`)

**Sword auto-equips on craft:**
- Craft handler now sets `save.equippedItem = 'sword'` immediately when sword is crafted.
  Previously the sword could be crafted into inventory but `equippedItem` was never set,
  so the +25 attack bonus never applied.

**Medicine locked behind Lena's quest:**
- `available` filter now excludes medicine if `!save.flags['lena_skill']`.
  Previously medicine was craftable by anyone regardless of whether they'd completed Lena's quest.

**[U] key uses consumables:**
- Added `uJustPressed` state var and `u`/`U` keydown handler.
- In main loop: pressing U uses medicine first (+50 HP), else ration (+40 hunger).
- Consumes one unit from inventory, removes stack when empty.
- `drawInventoryPanel()` now shows `[U] use` (teal) for owned consumables, and
  `equipped` / `in bag` (blue) for the sword instead of the craft prompt.

### 2. All gathering bonuses now applied (`src/game.ts`)

`gatherResource()` now multiplies all applicable bonuses:
- `betterToolsBonus` ×1.5 — if `better_tools` researched (was already applied for villagers via units.ts but not for the player's own gathering)
- `mayaBonus` ×1.5 — if `maya_skill` flag set AND food node
- `axeBonus` ×2 — if axe in inventory AND wood node
- `pickaxeBonus` ×2 — if pickaxe in inventory AND stone or coin node
- Fixed `catchmentBonus` 1.3 → 1.5 to match Water Catchment building description ("+50% food")

### 3. Masonry tech now reduces building costs (`src/game.ts`)

- `placeBuilding()`: computes `effectiveCost` with stone 25% reduced when masonry researched
- `drawBuildMode()`: panel displays the discounted stone cost and uses it for affordability check

### 4. Archery tech now gives soldiers ranged attack (`src/units.ts`)

- In `attacking` case: `effectiveRange` = 4.0 tiles if `u.kind === 'soldier'` and `'archery'` researched, otherwise `ATTACK_RANGE` (1.5). Soldiers now hang back and fire from distance when archery is unlocked.

### 5. Ghost ship gated by signal fire (`src/game.ts`)

- `updateWeather()`: ghost ship only drifts when `signal_fire` is built
- `drawGhostShip()`: returns early if no signal fire exists
  Previously the ghost ship appeared on any fog day regardless of whether the player had built a signal fire.

### 6. Species education popup on first plant (`src/game.ts`)

- After successfully planting a species, counts tiles of that speciesId in `save.plantedTiles`.
  If count is 1 (first ever tile), shows `educationPopup` with the species' `ecologicalFact`.
