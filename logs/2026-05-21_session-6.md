## Changes shipped

### 1. Font fix (`src/game.ts`)

All 74 instances of `"Courier New", monospace` in `ctx.font` strings replaced with
`"Space Mono", "Courier New", monospace`. Space Mono (loaded via Google Fonts) now renders
in the canvas, matching the DOM typography.

### 2. Building persistence (`src/game.ts`)

`placeBuilding()`, `craftShipPart()`, and the E-key tech research handler now each call
`triggerSave()` immediately after modifying `save.buildings` / `save.shipParts` /
`save.researched`. Previously these only persisted at the 2-minute auto-save interval.

### 3. Pause / resume on tab hide + close (`src/game.ts`, `src/main.ts`)

**Tab hidden (visibilitychange):**
- `cancelAnimationFrame(rafId)` — game loop stops instantly
- `triggerSave()` — pushes to GitHub
- Writes `faraway_draft` + `faraway_draft_time` to localStorage as crash backup
- On tab return: resets `lastRealTime = performance.now()` to avoid huge dt spike, then
  restarts the loop

**Tab/window closed (beforeunload):**
- Writes current state to `faraway_draft` + `faraway_draft_time` in localStorage

**On login (`src/main.ts`):**
- After loading cloud save, checks `faraway_draft`. If its timestamp is >3 s newer than
  the cloud save's `lastSaved`, the draft overwrites the resolved save. This recovers
  state from a session that ended without a successful GitHub push.

**triggerSave cleanup:**
- On successful cloud save, removes `faraway_draft` and `faraway_draft_time` from
  localStorage so stale drafts can't override a newer cloud state.

### 4. Ranger station damage — correct ×2 vs threat camps (`src/game.ts`)

`playerAttack()`: removed flat `rangerBonus = 10` from base damage. Added `hasRangerNearby`
bool. Threat camp hits now deal `campDmg = hasRangerNearby ? dmg * 2 : dmg`. Matches the
building description ("Combat damage ×2 vs. threat camps").

### 5. Threat camp cleanup + threats_cleared counter (`src/game.ts`)

After each attack loop, dead threat camps are filtered out of `save.threatCamps`.
`save.flags['threats_cleared']` is incremented on each defeat.

### 6. Raid spawning tied to live threat camps (`src/game.ts`)

`updateSurvival()`: replaced `(save.enemyCampHp ?? 400) > 0` with
`(save.threatCamps ?? []).some(tc => tc.hp > 0)` for both the raid-level escalation and
the daily raid spawn. The disconnected legacy `enemyCampHp` field no longer drives spawning.

### 7. Minimap shows actual threat camp positions (`src/game.ts`)

`drawMinimap()`: iterates `save.threatCamps` and draws a red dot at each live camp's real
`(tx, ty)`. Previously always rendered at hardcoded `(CAMP_X, CAMP_Y)`.
