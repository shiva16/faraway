### 8. Folk music engine (`src/music.ts`) — new file

12 traditional public-domain folk melodies synthesised entirely via Web Audio API:

| Track | Instrument |
|---|---|
| Scarborough Fair | flute |
| Greensleeves | dulcimer |
| Danny Boy | flute |
| The Water Is Wide | harp |
| Shenandoah | flute |
| Skye Boat Song | dulcimer |
| She Moved Through the Fair | flute |
| The Foggy Dew | harp |
| Wildwood Flower | dulcimer |
| Loch Lomond | harp |
| Black Is the Color | flute |
| The Parting Glass | dulcimer |

Instruments: `flute` (sine + vibrato LFO), `dulcimer` (triangle + exponential pluck decay +
2nd harmonic), `harp` (sine + 2nd harmonic, medium sustain).

Backing: per-track tonic+fifth drone (4 detuned sines, gain 0.038).
Master volume: 0.12 — well below game sound effects.
Scheduling: lookahead scheduler (0.35s ahead, 80ms poll) using Web Audio clock.
Track rotation: ~25% chance to advance after each full melody loop.
Track name displayed for 3s when it changes (bottom-centre HUD).
Starts on first user interaction (when `initAudio()` fires).

### 13. Mobile controls (`index.html`, `src/main.ts`)

**Portrait overlay**: CSS `@media (max-width:900px) and (orientation:portrait)` shows a
full-screen "rotate device" prompt with animated phone icon.

**Virtual D-pad** (bottom-left):
- 3×3 grid, 4 directional 48×48px buttons
- `pointerdown` → synthetic `KeyboardEvent('keydown')` to `window`
- `pointerup` / `pointerleave` → `keyup` — continuous movement while held

**Action buttons** (bottom-right, 2×3 grid, 56px wide):
- [ E ] Act, [ ⚔ ] Attack, [ B ] Build, [ P ] Plant, [ I ] Inventory, [ Esc ] Close
- Single-tap fires `keydown` + `keyup` (60ms apart)

**Canvas swipe**: `touchend` dispatches `ArrowLeft`/`ArrowRight` on swipe >55px (info panel
and plant catalogue page navigation).

**Long press** (420ms): dispatches `contextmenu` at touch position — unit move/attack
commands work on mobile.

Controls hidden on non-touch devices (`navigator.maxTouchPoints === 0`).

**Responsive login card**: `width: min(380px, calc(100vw-24px))` so it fits 360px phones.
