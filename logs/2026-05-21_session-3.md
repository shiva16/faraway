## EcoKnowGames GLV integration (new `src/ecology.ts`)

Ported the core simulation from `EcoKnowGames/simulator.R` and `find_matrix.R`:

```
ΔN_i = N_i × (r_i + Σ_j A_ij × N_j)
```

- `ecology.ts`: `stepGLV()`, `assessStability()`, `makeZone()`, `tickZone()`, `buildAMatrix()`, `speciesGrowthRate()`
- `botany.ts`: All 27 species now have `interactions: { speciesId: coefficient }` — the A-matrix row. Positive = facilitation, negative = competition.
- `game.ts`: 8×8 tile zones. Once per game day, zones run GLV simulation. Zone stability ('empty' / 'growing' / 'stressed' / 'thriving' / 'collapsed') displayed as map overlays:
  - Thriving: green shimmer + corner glow dots
  - Stressed: amber pulse  
  - Collapsed: grey + red ✗ icon
- Biodiversity HUD: now shows zone count by stability status
